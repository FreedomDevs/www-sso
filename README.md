# www-sso

## Запуск

```bash
pnpm install
pnpm dev
```

## Query Parameters

| Name        | Type                  | Required | Returned | Description                                                                                 |
|-------------|-----------------------|----------|----------|---------------------------------------------------------------------------------------------|
| `client_id` | `string`              | ✅        | ❌        | Идентификатор клиентского приложения.                                                       |
| `intent`    | `login` \| `register` | ❌        | ❌        | Определяет начальный сценарий авторизации. По умолчанию `login`.                            |
| `scope`     | `string`              | ❌        | ❌        | Дополнительные данные или запрашиваемые разрешения.                                         |
| `state`     | `string`              | ❌        | ✅        | Произвольная строка, которая возвращается клиенту без изменений после успешной авторизации. |
